## Specs

- **S1 — Dependency security:** "Autorizo Sharp como dependencia directa para el punto 2, pero no sharp@0.34.5. Revisá los avisos oficiales y elegí una versión estable corregida, actualmente 0.35.5 o posterior, compatible con nuestro entorno." Pin the verified stable `sharp@0.35.5` directly, without overriding Next.js's separate transitive dependency.
- **S2 — Generate once:** "Generá la preview una sola vez al cargar o reemplazar la imagen." Generate the private derivative during authorized upload/finalization only, including idempotent retry handling; never transform on reads or idle renewal.
- **S3 — Privacy and integrity:** "Conservá el original intacto, los permisos privados y una limpieza consistente." Preserve original bytes, private access, existing actor/profile/lifecycle authorization and 300-second signed URL lifetime. Include preview objects in replacement, removal, reconciliation and purge handling. Existing originals are not batch-modified; legacy rows retain a safe fallback.
- **S4 — Validate before processing:** "Validá formatos reales, tamaño y cantidad de píxeles antes de procesar." Accept only actual JPEG/PNG/WebP matching the declared type, retain the 10 MiB original limit, inspect decoder metadata before resizing and enforce a documented bounded pixel budget. Reject invalid/truncated or excessive inputs without committing image metadata.
- **S5 — Compatibility and proof:** "Verificá compatibilidad con Node, Next.js y el despliegue, además de las pruebas focalizadas y la medición antes/después. No fuerces versiones transitivas de Next.js sin evaluar su compatibilidad." Verify direct/native runtime and lockfile compatibility, focused regressions and before/after local traffic. Distinguish checked build/package evidence from an actual cloud deployment, which is not authorized.
- **S6 — Remaining approved optimizations:** "continua con el punto 2,3 y 4 y al final dame una breve explicacion d qhiciste en cada punto" Point 2 serves private previews while retaining intentional original access. Point 3 reuses valid URLs only in authenticated client memory and avoids successful ordinary moves returning a full board, preserving conflict reconciliation. Point 4 narrows quick-view reads and server-filters bag/flag enrichment without weakening existing role/lifecycle rules. Finish with a brief explanation per point.
- **S7 — Scope boundaries:** "No modifiques pedidos existentes ni cuentas." Existing measurement permission covers only new synthetic local fixtures. Do not change existing orders/accounts, production, remote data/schema, deployment or plan. Preserve point 1 and all pre-existing workspace edits; no commits or pushes.
- **S8 — Next update:** "Actualizá Next.js a 16.4.5, previa confirmación de la versión publicada y su compatibilidad. Verificá qué versiones de Sharp quedan resueltas en el lockfile. No uses overrides ni amplíes la actualización a paquetes ajenos sin necesidad."
- **S9 — Unknown movement:** "Corregí el movimiento cuando el RPC responde sin error pero sin resultado: tratá el estado como desconocido y consultá el estado canónico. Si no se puede confirmar, mostrā “Estado no confirmado”. No asumas éxito ni que la operación fue rechazada; conservá idempotencia y manejo de conflictos."
- **S10 — Targeted proof and staging handoff:** "Ejecutá las pruebas focalizadas de estos cambios y un build para verificar la actualización de Next. Incluí regresión para respuesta vacía y reconciliación fallida. La suite completa queda al CI." Deliver the requested app/purge deployment order, legacy/new image validation and orphan checks without executing remote operations.
